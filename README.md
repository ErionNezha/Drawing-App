# 🎨 Studio Vizatimi

Canvas profesional vizatimi me penela, ngjyra, undo/redo dhe shkarkim PNG.

Canvas profesional vizatimi në browser — pa server, pa llogari, gjithçka në shfletuesin tënd.

## ✨ Veçori

- 🖊️ Penel me 10 ngjyra + ngjyrë të personalizuar
- 📏 Trashësi e rregullueshme (1–50 px)
- 🧽 Gomë precize
- ↩️↪️ Undo / Redo (deri në 30 hapa) + shkurtore Ctrl+Z / Ctrl+Y
- 🌗 Sfond i bardhë / i errët
- 🗑️ Pastrim i shpejtë (i kthyeshëm me Undo)
- ⬇️ Shkarkim si PNG (`vizatim.png`)
- 📱 Mbështetje touch (vizatim me gisht)
- 🖥️ Canvas responsive me rezolucion të lartë (devicePixelRatio)
